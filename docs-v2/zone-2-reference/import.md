# Import — Valeurs acceptées

Valeurs et formats acceptés pour la fonctionnalité d'import bulk.

## Couleurs

| Nom | Code hexadécimal |
|-----|-----------------|
| Bleu | `#0000FF` |
| Magenta | `#FF00FF` |
| Marron | `#A52A2A` |
| Noir | `#111111` |
| Orange | `#FFA500` |
| Rouge | `#991B1B` |
| Vert | `#065F46` |
| Violet | `#800080` |

> Les codes pour Rouge, Noir et Vert sont repris des couleurs de conformité par défaut de la plateforme.

## Rôles d'utilisateurs

Valeurs possibles :

- `Lecteur`
- `Utilisateur`
- `Administrateur`
- `Administrateur principal`
